# Genius-Homes Wiki

Welcome to the Genius-Homes documentation.

Genius-Homes is a configurable Minecraft homes plugin for Paper servers. It supports GUI-based home management, configurable menus, language files with fallback support, teleport cooldowns, optional teleport costs, SQLite/MySQL storage, and AnvilGUI text input.

## Getting Help

For setup help and support, join the Discord:

https://discord.gg/2kXkEUMeta

When asking for help, include your server version, Genius-Homes version, relevant config files, console errors, and `plugins/Genius-Homes/debug.log`.

## Reporting Issues

Use GitHub Issues for bugs and feature requests. Include steps to reproduce, expected behavior, actual behavior, server/plugin versions, and any relevant logs.

Do not post private database credentials or other secrets in public issues.
